# CSP3341 Weather Dashboard

A cross-platform desktop Weather Dashboard developed in C# 12 and .NET 8 using Avalonia UI on macOS.

## Technologies

- C# 12
- .NET 8
- Avalonia UI
- SQLite
- HttpClient
- Git and GitHub

## Project Status

This repository currently contains the initial Avalonia desktop application prototype. Weather API integration, SQLite caching, charts, and role-based administration are planned for later development stages.

## Run the project

```bash
dotnet restore
dotnet build
dotnet run
```
